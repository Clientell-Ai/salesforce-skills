# sf-lwc Evaluation

## Should Trigger
- "Scaffold a new Lightning Web Component that displays a list of Contacts"
- "Create a Jest test for my accountCard LWC"
- "Build an LWC with a lightning-datatable showing Opportunity records"
- "Add a search bar to my existing Lightning Web Component"
- "Create a parent-child LWC composition for a dashboard widget"
- "Write a Lightning Web Component that uses wire service to fetch records"
- "My LWC is not rendering correctly in the Lightning App Builder"
- "Create a custom LWC property editor for a Flow screen component"
- "Build an LWC that uses lightning-record-edit-form for inline editing"
- "Help me implement pub-sub communication between two LWC components"
- "Generate the XML metadata file for my LWC with all target configs"
- "Convert my old Aura component to a Lightning Web Component"

## Should NOT Trigger
- "Write an Apex controller method that my LWC will call" (expected: sf-apex)
- "Write a test class for the Apex controller behind my LWC" (expected: sf-test)
- "Build a Flow screen that captures user input" (expected: sf-flow)
- "Write a SOQL query to fetch data for my component" (expected: sf-soql)
- "Check my LWC's Apex controller for CRUD violations" (expected: sf-security)
- "Deploy my LWC bundle to production" (expected: sf-deploy)
- "Import CSV data to populate my LWC demo" (expected: sf-data)
- "Create a custom object that my LWC will display" (expected: sf-schema)
- "I want to build a custom UI but I'm not sure what technology to use" (expected: sf-find)
- "Create a Visualforce page with an embedded iframe" (expected: sf-apex)
- "Audit the JavaScript in my component for XSS vulnerabilities" (expected: sf-security)
- "Set up CI/CD to automatically deploy my components on commit" (expected: sf-deploy)
