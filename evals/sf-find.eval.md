# sf-find Evaluation

## Should Trigger
- "I need help with Salesforce but I don't know where to start"
- "What skill should I use to automate a business process?"
- "Can you help me figure out the right approach for my requirement?"
- "I'm new to Salesforce development, what tools are available?"
- "Which skill handles creating custom UI components?"
- "I have a requirement but I'm not sure if I need code or configuration"
- "What's the difference between using a Flow and writing Apex?"
- "Help me decide between a trigger and a Flow for my automation"
- "What Salesforce skills do you have?"
- "I want to do something in Salesforce but I'm not sure what it's called"
- "Can you recommend which approach to take for integrating with an external API?"
- "List all the Salesforce capabilities you can help me with"

## Should NOT Trigger
- "Write an Apex trigger on the Account object" (expected: sf-apex)
- "Generate a test class for my controller" (expected: sf-test)
- "Create a record-triggered Flow on Opportunity" (expected: sf-flow)
- "Scaffold a new Lightning Web Component" (expected: sf-lwc)
- "Write a SOQL query to get all Contacts with their Accounts" (expected: sf-soql)
- "Audit my code for security vulnerabilities" (expected: sf-security)
- "Deploy my changes to production using sfdx" (expected: sf-deploy)
- "Bulk load 50,000 records into my sandbox" (expected: sf-data)
- "Create a custom object with three fields" (expected: sf-schema)
- "Fix my failing Apex test that's throwing a null pointer exception" (expected: sf-test)
- "Optimize my SOQL query that's hitting governor limits" (expected: sf-soql)
- "Migrate my Process Builder to a Flow" (expected: sf-flow)
